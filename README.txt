Ritchad PA - native Android (Kotlin + Jetpack Compose)
1. Install Android Studio (Koala or newer).
2. File > Open > select this RitchadPA folder; let Gradle sync (it creates the wrapper).
3. Plug in your Android phone (USB debugging on) and press Run, or Build > Build APK(s).

PHONE-ONLY BUILD: upload these files to a new GitHub repo; the Actions tab builds the APK. Download "RitchadPA-apk" from the finished run.
